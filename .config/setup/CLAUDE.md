# Desktop Setup — ~/.config/setup

Bootstraps a fresh Arch Linux + Hyprland desktop after `archinstall`.
Scripts live in `desktop/` (tracked by yadm). Static config files belong in yadm directly — scripts only run commands, never write dotfiles.

## File layout

```
~/.config/setup/
├── CLAUDE.md
└── desktop/
    ├── 1-post-install.sh   # Run from archinstall env before reboot — LUKS/TPM, GRUB, mkinitcpio
    ├── 2-bootstrap.sh      # Entry point — calls all scripts/ in order, prints manual steps at end
    └── scripts/
        ├── 1-packages.sh   # pacman + yay installs, rustup
        ├── 2-shell.sh      # Oh My Zsh, chsh to zsh
        ├── 3-neovim.sh     # Clone kickstart.nvim, install plugins headlessly
        ├── 4-fonts.sh      # Write /etc/fonts/local.conf (uses sudo), fc-cache
        ├── 5-sddm.sh       # Write /etc/sddm.conf.d/theme.conf (uses sudo)
        └── 6-launcher.sh   # Install walker + elephant (services started by hyprland.lua)
```

## Bootstrap flow (new machine)

1. Run `archinstall`
2. `bash ~/.config/setup/desktop/1-post-install.sh <device> <luks-uuid>`
3. Reboot
4. `pacman -S yadm git age`
5. `yadm clone https://github.com/Encephala/yadm` (HTTPS — no key yet)
6. `yadm decrypt` — restores SSH key + SSH config, prompts for age passphrase
7. `yadm remote set-url origin git@github.com:Encephala/yadm`
8. `bash ~/.config/setup/desktop/2-bootstrap.sh`

## yadm

Dotfiles repo: https://github.com/Encephala/yadm

Sensitive files encrypted with age (`yadm config yadm.cipher age`), listed in `~/.config/yadm/encrypt`:
- `~/.ssh/id_ed25519`
- `~/.ssh/id_ed25519.pub`
- `~/.ssh/config`

Static config files tracked by yadm (not generated by scripts):
- `~/.zshrc`
- `~/.zprofile`
- `~/.gitconfig`
- `~/.local/bin/dsf-filter`
- `~/.config/hypr/hyprland.lua`
- `~/.config/hypr/hypridle.conf`
- `~/.config/hypr/hyprlock.conf`
- `~/.config/waybar/` (config.jsonc, style.css, power_menu.xml)
- `~/.config/walker/` (config.toml, themes/tokyo-night/style.css)
- `~/.config/elephant/desktopapplications.toml` (usage-history sorting)
- `~/.config/elephant/menus/` (zed-workspaces.lua, steam-games.lua)
- `~/.config/systemd/user/elephant.service`
- `~/.config/systemd/user/walker.service`
- `~/.config/yadm/encrypt`
- `~/.config/setup/` (the scripts themselves)

Do not put secrets in `~/.zshrc` / `~/.zprofile` — they are tracked unencrypted. Use a separate sourced file added to `~/.config/yadm/encrypt` instead.

## Script responsibilities

### 1-post-install.sh
Runs pre-reboot from the archinstall environment. Takes `<device>` and `<luks-uuid>` as arguments.
1. Enrol TPM2 into the LUKS slot (`systemd-cryptenroll`)
2. Patch `/etc/default/grub` to add `rd.luks.name=UUID=<luks-uuid>=cryptroot`
3. `grub-mkconfig`
4. Rewrite HOOKS in `/etc/mkinitcpio.conf` to the systemd-based set, then `mkinitcpio -P`

### 1-packages.sh
Installs the packages not owned by any other script (base tools, Hyprland stack, terminal tools, misc apps), plus the yay bootstrap itself. Package installs specific to a later script's concern live in that script instead.
1. Install `base-devel` via pacman (needed to build yay)
2. `pacman -S` the remaining pacman packages (base tools, editor apps not tied to a script, Hyprland stack, terminal & files, rustup, age)
3. Clone and build yay from AUR (`https://aur.archlinux.org/yay.git`)
4. `yay -S` the remaining AUR packages (hyprmod, synology-drive, vesktop)
5. `rustup default stable`

### 2-shell.sh
1. `pacman -S zsh`, `yay -S oh-my-zsh-git`
2. Install Oh My Zsh via upstream script (unattended, to `~/.oh-my-zsh`)
3. `chsh -s /usr/bin/zsh`

### 3-neovim.sh
1. `pacman -S neovim gcc npm unzip luarocks`, `yay -S tree-sitter-cli`
2. Clone `https://github.com/Encephala/kickstart.nvim` into `~/.config/nvim`
3. Run `nvim --headless "+Lazy! sync" +qa` to install plugins

### 4-fonts.sh
1. `pacman -S` the Nerd Font + Font Awesome + emoji font packages
2. Write `/etc/fonts/local.conf` with CaskaydiaMono Nerd Font as monospace default (sudo)
3. `fc-cache -f`

### 5-sddm.sh
1. `yay -S sddm-theme-tokyo-night-git`
2. Write `/etc/sddm.conf.d/theme.conf` setting `Current=tokyo-night` (sudo)

### 6-launcher.sh
1. `yay -S walker elephant elephant-desktopapplications elephant-calc elephant-menus`

Services are not enabled. `hyprland.lua`'s `hyprland.start` hook runs `systemctl --user start` for `elephant.service` (walker's data backend) and `walker.service` (resident `walker --gapplication-service`, for instant popup). SDDM launches plain Hyprland (not uwsm), so `graphical-session.target` never activates, and `default.target` starts before a display exists — walker would fail with "Failed to open display".

Both unit files live in `~/.config/systemd/user/` and are tracked by yadm (not written by any script); `walker.service` has no `[Install]` section on purpose. Walker's own config (`~/.config/walker/`) and its Lua menus (`~/.config/elephant/menus/` — Zed workspaces, installed Steam games) are also tracked by yadm, not generated by scripts.

## Manual steps (printed by 2-bootstrap.sh at the end)

- **Hyprland local config**: create `~/.config/hypr/hyprland-local.lua`
  (monitor layout, cursor size, touchpad, brightness keys — device-specific, gitignored)
- **Hyprlock local config**: create `~/.config/hypr/hyprlock-local.conf` (gitignored)
- **Hyprland GUI config**: `~/.config/hypr/hyprland-gui.lua` is managed by hyprmod, generated automatically
- **Synology Drive**: verify the service started; configure sync folders
- **Relog** for `chsh` to take effect

## Notes

- Oh My Zsh installed via upstream script (not AUR) so `~/.oh-my-zsh` path in `.zshrc` stays correct
- `dsf-filter` in `~/.local/bin/` is a thin wrapper required by `git config interactive.diffFilter`; `diff-so-fancy` itself is installed via pacman
- zoxide is installed via pacman (available in Arch repos), not cargo
- `~/.gitconfig` `signingkey` is hardcoded to `/home/jonathan/.ssh/id_ed25519.pub`
- starship provides the prompt; Oh My Zsh is used only for its plugin infrastructure (completions etc.)
